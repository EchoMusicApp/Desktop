# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in **Echo Music Desktop**, please report it responsibly rather than opening a public issue.

- **Contact**: Email `hello@echomusic.fun` or open a private security advisory on [GitHub Security Advisories](https://github.com/EchoMusicApp/Desktop/security/advisories/new).
- **Include**: Steps to reproduce, affected version/platform, and potential impact.

We will acknowledge your report and work on a fix promptly.
